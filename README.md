# MnemoBudget

Say what you spend and what you plan to spend. Sort it into pockets
(home, the shop, the children). See what is spent, what is coming and
what is left this month. Your files, on your machine.

## What it does

- Write a paid expense or a planned one, by voice or by hand.
- Group lines into pockets and categories.
- Set a monthly cap on a category and see what remains.
- Ask for a summary of the month, a pocket or a category.

## Install

1. Get [Mnemosyne OS](https://mnemosyne-os.io/download).
2. In MnemoHub, paste this repository URL, or install from the store once
   the listing is live.
3. Open **MnemoBudget** from the dock.
